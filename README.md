# Gerenciamento de Livraria

Sistema de gerenciamento de livraria desenvolvido para praticar meus conhecimentos em **ASP.NET Core MVC** e **Entity Framework Core**. O projeto permite o controle completo (CRUD) de livros

## Tecnologias Utilizadas

* **Linguagem:** C#
* **Framework:** ASP.NET Core MVC 8.0 
* **Banco de Dados:** SQL Server
* **ORM:** Entity Framework Core
* **Front-end:** Bootstrap 5, Razor Views e Bootstrap Icons

##  Funcionalidades

- [x] Cadastro de novos livros.
- [x] Listagem com busca visual (Index).
- [x] Edição de dados existentes.
- [x] Visualização detalhada dos livros.
- [x] Exclusão segura de registros.
